## Exercise 6.1

Explain the difference between the following pairs of terms.

### a. Counting loop and conditional loop

- **Counting loop:** The number of iterations is known and set. Example: specifying the number of rows and columns.
- **Conditional loop:** The number of iterations can vary and depends on a certain condition being satisfied.

### b. `for` statement and `while` statement

- **`for` statement:** Specifies the initial value, the condition, and the updater.
- **`while` statement:** Specifies what must be true or false for the loop body to execute, as long as the condition holds.

### c. `while` statement and `do`-`while` statement

- **`while` statement:** Specifies what must be true or false for the loop body to execute, as long as the condition holds.
- **`do`-`while` statement:** Specifies what must be true or false for the loop body to execute, as long as the condition holds, and what action is done while the condition is satisfied.

### d. Zero indexing and unit indexing

- **Zero indexing:** Starts at 0.
- **Unit indexing:** Starts at 1.

### e. Sentinel bound and limit bound

- **Sentinel bound:** A value set for the loop to terminate; it prevents an infinite loop.
- **Limit bound:** Prevents infinite loops by ensuring the set value will eventually be reached.
