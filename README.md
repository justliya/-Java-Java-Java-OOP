# Java Java Java — Notes and Exercises

Study notes, UML diagrams, and original Java exercise solutions organized by the book's three-part progression.

## Layout

- `Part-I-Object-Orientation-Basics/` — Chapters 0–4
- `Part-II-Language-Elements/` — Chapters 5–9
- `Part-III-Advanced-Topics/` — Chapters 10–16
- `Resources/` — reusable reference material

Each chapter uses the same structure:

- `notes/` — Markdown concept notes
- `exercises/` — exercise prompts, work, and solutions
- `src/` — Java source files; public class names must match filenames
- `diagrams/` — UML diagrams and flowcharts

UML assets should use clear names such as `Riddle_Class_Diagram.png` or `Student_Hierarchy.png`. Embed diagrams in the relevant Markdown notes where useful.
